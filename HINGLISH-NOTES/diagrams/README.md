# 📊 Diagrams

Ye `.excalidraw` files hain — editable visual notes.

## Kaise kholein

**Option 1 — Browser (kuch install nahi karna)**
1. [excalidraw.com](https://excalidraw.com) kholo
2. Menu (top-left) → **Open** → yahan se file select karo

**Option 2 — VS Code (best, kyunki repo ke andar hi rahega)**
1. Extensions me search karo: **"Excalidraw"** (publisher: *pomdtr*)
2. Install karo
3. `.excalidraw` file pe click karo — canvas seedha VS Code me khul jaayega

> Diagrams **editable** hain. Apne notes add karo, colors badlo, apne examples likho.
> Khud se banaya hua diagram 10x zyada yaad rehta hai.
